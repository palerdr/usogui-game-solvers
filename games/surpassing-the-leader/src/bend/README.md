# Pure Drop the Handkerchief in Bend

The Bend code computes the profile quotient, the revival and transition
rules, and the certified stage values in the [DTH specification](../../docs/DTH.md).
The C driver schedules independent classes within each layer and stores
the table in an STL-compatible NumPy artifact. Every stage must pass the
`1e-6` saddle gap before the driver writes its midpoint. The full solve
uses the pure saddle and equalizer rungs. The driver stops if neither
certifies a stage.

## Build and verify

Run these commands from the Usogui root with Python 3.12+ and Clang 14+.
The build uses Bun from `PATH` or obtains it through `npx`. It downloads and
checks the pinned Bend 2.0.40 source archive and builds in a temporary
directory. Set `BUN` or `CC` to pick an executable. Pass `--source` to use a
local copy of the archive.

```sh
port=games/surpassing-the-leader/src/bend
mkdir -p artifacts/dth-bend
python3 -B "$port/build.py" artifacts/dth-bend/dth-bend
artifacts/dth-bend/dth-bend artifacts/dth-bend/V.npy
cmp artifacts/dth-bend/V.npy artifacts/dth/V.npy
```

The verifier checks each float64 value, including the signed zero bits.
`artifacts/dth/V.npy` is the existing reference generated by the Rust or
Numba solver. The Bend driver reports the root, the maximum saddle gap,
the counts by rung, and elapsed time before it publishes the 2.16 GiB
artifact. It refuses to replace an existing output. The driver defaults to
one worker and stops when macOS reports elevated memory pressure. The table
mapping still uses up to 2.16 GiB of file-backed pages.

Use stop layer 1082 to check the 7,140-state endgame against its committed
fixture. The argument after the stop layer sets the number of CPU workers.

```sh
artifacts/dth-bend/dth-bend artifacts/dth-bend/dead-band.npy 1082
uv run --project games/surpassing-the-leader --locked python "$port/verify.py" \
  --dead-band artifacts/dth-bend/dead-band.npy crates/stl-dth/tests/data/dead_band.bin
```

## Verified full build

On the 15-core Apple M5 Pro, the sweep and artifact write took 390.369 s.
The solver certified all 289,374,121 classes. It used the pure saddle for
334,177 classes and the equalizer for 289,039,944. The maximum stage gap
was `9.876061544122905e-7` and the root value was `0.089850072814138607`.
All table entries matched the reference bit for bit. The Rust verifier
passed its six anchors and 1,200 strided rechecks.

The complete artifact SHA-256 is
`e43977b7a2aa9be6cb7708465ed52989380bb8a787fcedd6f7929ee14ffd29b2`.

## Numerical representation

Bend 2.0.40 supplies float32. The build extends its CPU emitter with
`F64` operations backed by C binary64. Bend checks the profile and stage
modules before emitting the solver. The native arithmetic is trusted
and the numerical certificates are checked during the sweep. The build
disables fused multiply-add to preserve the reference operation order.
Exact revival bits depend on the host `pow` implementation.
